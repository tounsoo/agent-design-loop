# Add the board page type

## Reason

Invoices grouped by stage read better as a board than as a table.

## Preview

A collection page with one column per stage, named under shells.collections with the Heading and Description chrome.

## Adoption

`inputs.ts` lists `board`, `page-types/board` holds its shell, and the config names it under `shells.collections`.

## States

- Ready: one column per stage, each with its invoices.
- Empty: Out of scope, the fixture renders no board page.
- Loading: Out of scope, the fixture renders no board page.
- Error: Out of scope, the fixture renders no board page.
- Long content: Out of scope, the fixture renders no board page.
- Permissions: Out of scope, the fixture renders no board page.
- Over time: Out of scope, the fixture renders no board page.
