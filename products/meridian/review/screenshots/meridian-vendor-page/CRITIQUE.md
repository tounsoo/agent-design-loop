# Critique

Round 1, by Claude Sonnet, which did not build the change: pass, with 4 for the review note. Written by `npm run critique` from the critic's findings on this folder's screenshots. It is advisory: no check reads it.

## For the review note

- **Hierarchy** (`after/vendors--desktop-dark.png`, `after/vendors--desktop-light.png`, `after/vendors--phone-dark.png`, `after/vendors--phone-light.png`, `after/vendor-added--desktop-dark.png`, `after/vendor-added--desktop-light.png`, `after/vendor-added--phone-dark.png`, `after/vendor-added--phone-light.png`, `after/vendor-unknown--desktop-dark.png`, `after/vendor-unknown--desktop-light.png`, `after/vendor-unknown--phone-dark.png`, `after/vendor-unknown--phone-light.png`): The change turns every vendor card name into a bold, underlined link. In the three-column grid the repeated underlined names are the loudest thing under the page title and pull the eye ahead of the search field. The title 'Vendors' is still larger, so it holds, but the underlines add weight the before screenshots did not have. Fix: Keep the card name as a link but drop the permanent underline (show it on hover/focus) or use a lighter link style, so the grid reads quieter than the title.
- **Grouping** (`after/vendor-harbor-and-pine--desktop-dark.png`, `after/vendor-harbor-and-pine--desktop-light.png`, `after/vendor-harbor-and-pine--phone-dark.png`, `after/vendor-harbor-and-pine--phone-light.png`, `after/vendor-helios-freight--desktop-dark.png`, `after/vendor-helios-freight--desktop-light.png`, `after/vendor-helios-freight--phone-dark.png`, `after/vendor-helios-freight--phone-light.png`, `after/vendor-no-invoices--desktop-dark.png`, `after/vendor-no-invoices--desktop-light.png`, `after/vendor-no-invoices--phone-dark.png`, `after/vendor-no-invoices--phone-light.png`, `after/vendor-nothing-open--desktop-dark.png`, `after/vendor-nothing-open--desktop-light.png`, `after/vendor-nothing-open--phone-dark.png`, `after/vendor-nothing-open--phone-light.png`): On the vendor detail pages the Remittance / Terms / Open total list sits almost against the page title with no gap, while the gap to the first section heading is much larger. The facts read as a subtitle jammed under the h1 rather than as their own block. The breadcrumb also repeats the vendor name shown in the title directly below it. Fix: Add space between the title and the facts list, matching the space used before section headings. The breadcrumb's last item could be dropped or kept quieter, since the title already names the vendor.
- **Crowding** (`after/vendor-harbor-and-pine--phone-dark.png`, `after/vendor-harbor-and-pine--phone-light.png`, `after/vendor-helios-freight--phone-dark.png`, `after/vendor-helios-freight--phone-light.png`): On a phone the Open invoices table is squeezed: headers and values break mid-word ('Invoi ce', 'Amo unt', 'INV-177 0', '$41 0.00', '$12,64 0.50'), while the Status badge column keeps its width. The table is hard to read and the amounts, which matter most, are split. Fix: On narrow widths let the table scroll sideways inside its own container or stack each invoice as a small block, and never break invoice numbers or amounts across lines (no-wrap on those cells).
- **Crowding** (`after/vendor-no-invoices--desktop-dark.png`, `after/vendor-no-invoices--desktop-light.png`, `after/vendor-no-invoices--phone-dark.png`, `after/vendor-no-invoices--phone-light.png`, `after/vendor-nothing-open--desktop-dark.png`, `after/vendor-nothing-open--desktop-light.png`, `after/vendor-nothing-open--phone-dark.png`, `after/vendor-nothing-open--phone-light.png`): A vendor with a very long name fills the whole title row on desktop and takes four lines on a phone, pushing the facts and the empty-state line down. A vendor with no open invoices still shows 'Open total $0.00' as a full-weight fact, repeating what the empty state already says. Fix: Let long names wrap at a smaller title size or truncate with the full name in the breadcrumb. Drop or quiet the $0.00 total when the page already says there is nothing open.
